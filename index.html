pipeline.py
# From dataset to evaluated model
import algorithm_genome as ag

result = (
    ag.Pipeline("experiment")
    .load("training.csv")
    .target("label")
    .preprocess(
        missing="auto",
        categorical="auto",
        scale="auto"
    )
    .split(test_size=0.2, cv=5)
    .select_model(task="classification")
    .evaluate(metrics=["accuracy", "f1_macro"])
    .run()
)

print(result.best_model)
print(result.metrics)

Composable building blocks built around how machine-learning practitioners actually work—not around repetitive training scripts.

compare_models.py
import algorithm_genome as ag

models = [
    "logistic_regression",
    "random_forest",
    "decision_tree",
    "knn",
    "svm",
    "gradient_boosting",
    "extra_trees",
    "naive_bayes",
]

result = (
    ag.Pipeline("wine", random_state=42)
    .load("wine.csv")
    .target("target")
    .split(test_size=0.2, cv=3)
    .select_model(
        task="classification",
        candidates=models
    )
    .run()
)
print(result.leaderboard)

COMMON QUESTIONS

Good to know.

Is Algorithm Genome already on PyPI?

The website documents source version 1.0.0rc3. Do not assume this release candidate is published. For this version, install the source checkout with python -m pip install -e .. Check the official package registry for published versions.

Does it implement every ML algorithm?

No. It provides curated models, algorithm discovery from your installed scikit-learn distribution and a custom registration interface. Not every discovered estimator can fit arbitrary datasets.

How is it different from scikit-learn?

Algorithm Genome is a higher-level layer for comparing and orchestrating ML pipelines using existing estimator implementations. scikit-learn remains an important internal dependency.

Is it ready for production workloads?

It is a release candidate. Evaluate compatibility, model quality, security and performance for your use case before deploying. Distributed ML execution is not a current core capability.
